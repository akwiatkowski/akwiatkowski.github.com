# JSON Endpoints

Documentation of all JSON endpoints generated by `special_view/` generators.

## Endpoint Summary

| URL | Generator | Size | Used By |
|-----|-----------|------|---------|
| `/payload.json` | `PayloadJsonGenerator` | ~5 MB | map.js, summary.js, area_show.js |
| `/photos.json` | `PhotosJsonGenerator` | ~20 MB | timeline.js, panoramio, area_show.js |
| `/ideas.json` | `IdeasJsonGenerator` | ~510 KB | ideas.js |
| `/train_stations.json` | `TrainStationsJsonGenerator` | ~6 KB | ideas.js, planner.js |
| `/nav_stats.json` | `NavStatsJsonGenerator` | ~6.5 KB | nav_stats.js |
| `/jsons/homepage.json` | `HomePageJsonGenerator` | ~11 KB | homepage.js, post_collection.js |
| `/jsons/map.json` | `MapJsonGenerator` | ~16 KB | map_leaflet.js |
| `/jsons/photo_grid.json` | `PhotoGridJsonGenerator` | ~14 KB | planner.js |

**Size:** ~5 MB (mostly GPS coordinates)
**Used by:** map.js, summary.js, area_show.js

      "slug": "pagorki",
      "title": "Post Title",
      "subtitle": "Subtitle",
      "visible": true,
      "ready": true,
      "category": "bicycle",
      "date": "2021-07-18",
      "time": "2021-07-18T12:00:00+02:00",
      "distance": 65.5,
      "time_spent": "6h 30m",
      "year": 2021,
      "month": 7,
      "image_url": "/path/to/image.jpg",
      "card_image_url": "/path/to/card.jpg",
      "tags": ["bicycle", "mountains"],

## `/photos.json` — Full Photo Metadata

**Generator:** `PhotosJsonGenerator` (priority 54)
**Size:** ~20 MB (25,000+ photos)
**Used by:** timeline.js, panoramio (photo map), area_show.js
**Filter:** Only photos with desc >= 4 chars

```json
{
  "routes": [],
  "photos": [
    {
      "desc": "Photo description",
      "full_url": "/photos/full/photo.jpg",
      "article_url": "/photos/article/photo.jpg",
      "time": "2021-07-18T14:30:00+02:00",
      "post_slug": "pagorki",
      "post_url": "/2021/07/18-pagorki.html",
      "is_published": true,            // true if photo has any tags
      "points": 15,
      "tags": ["best", "landscape"],

      // EXIF data (flat keys, only if exif data exists)
      "exif.lat": 52.1234,             // nullable
      "exif.lon": 16.5678,             // nullable
      "exif.altitude": 150.0,          // nullable
      "exif.focal_35mm": 24,           // nullable
      "exif.aperture": 8.0,            // nullable
      "exif.exposure": 0.002,          // nullable (in seconds)
      "exif.iso": 200,                 // nullable
      "exif.lens_name": "Sigma 24mm",  // nullable
      "exif.camera_name": "Sony A7",   // nullable
      "exif.time": "2021-07-18T14:30:00+02:00"  // nullable
    }
  ]
}
```

**Note:** EXIF fields use flat key notation (`"exif.lat"` not nested `exif: {lat: ...}`).
Frontend accesses as `photo['exif.lat']`.

## `/ideas.json` — Trip Ideas Data

**Generator:** `IdeasJsonGenerator` (priority 53)
**Size:** ~510 KB
**Used by:** ideas.js (trip ideas page)

```json
{
  "towns": [
    {
      "slug": "pobiedziska",
      "name": "Pobiedziska",
      "url": "/gmina/pobiedziska.html"  // null if town has no rendered page
    }
  ],
  "ideas": [
    {
      "slug": "idea-slug",
      "link": "https://external-route-link",
      "distance": 85.5,
      "elevation": 1200,
      "lindays_mink": 1,               // NOTE: typo (should be days_min)
      "days_normal": 2,
      "start": 2.5,                    // train hours from Poznan to start
      "finish": 3.0,                   // train hours from Poznan to finish
      "direction": 135.0,              // bearing in degrees
      "direction_char": "045 - ...",   // compass label
      "time_cost_stats_for_new_town": 4.5,
      "surfaces": ["asphalt", "gravel"],
      "towns": ["town1", "town2"],
      "photo_map_url": "/path/to/map",
      "towns_already_visited": ["town1"],
      "towns_not_visited": ["town2"]
    }
  ]
}
```

## `/nav_stats.json` — Navigation Statistics

**Generator:** `NavStatsJsonGenerator` (priority 57)
**Size:** ~6.5 KB
**Used by:** nav_stats.js (navigation dropdown menus)

    {
      "name": "Wielkopolskie",
      "slug": "wielkopolskie",
      "type": "voivodeship",
      "url": "/wojewodztwo/wielkopolskie.html",

    {
      "name": "Pojezierze",
      "slug": "pojezierze",
      "type": "land",
      "url": "/...",
      "count": 12,
      "html_id": "nav-pojezierze"
    },
    {
      "name": "rowerem",
      "slug": "rowerem",
      "type": "tag",

## `/jsons/homepage.json` — Homepage Data

**Generator:** `HomePageJsonGenerator` (priority 52)
**Size:** ~11 KB
**Used by:** homepage.js, post_collection.js

```json
{
  "posts": [
    {
      "url": "/2021/07/18-pagorki.html",
      "title": "Post Title",
      "subtitle": "Subtitle",
      "visible": true,
      "ready": true,
      "date": "2021-07-18",
      "time": "2021-07-18T12:00:00+02:00",
      "distance_km": 65.5,
      "time_spent": "6h 30m",
      "card_image_url": "/path/to/card.jpg",
      "tags": ["bicycle", "mountains"],
      "photos": [
        {"src": "/photos/card/best.jpg", "alt": "Description", "points": 15}
      ],
      "town_slugs": ["pobiedziska"],
      "meso_region_slugs": ["pojezierze_gnieznienskie"]
    }
  ],
  "tags": [
    {"slug": "bicycle", "url": "/wpisy-dla/tagu/rowerem.html", "name": "rowerem"}
  ],
  "towns": [
    {"slug": "pobiedziska", "url": "/wpisy-dla/gminy/pobiedziska.html", "name": "Pobiedziska"}
  ],
  "meso_regions": [
    {"slug": "pojezierze_gnieznienskie", "url": "/wpisy-dla/regionu/pojezierze_gnieznienskie.html", "name": "Pojezierze Gnieznienskie"}
  ]
}
```

**Key difference from payload.json:** No coords, no image_url, no year/month, no full area arrays. Includes top 4 photos per post for hero image selection.

## `/jsons/map.json` — Route Map Data

**Generator:** `MapJsonGenerator` (priority 52)
**Size:** ~16 KB (dev) / ~300 KB (prod)
**Used by:** map_leaflet.js (route map page)
**Filter:** Only posts with GPS coordinates

```json
{
  "posts": [
    {
      "url": "/2021/07/18-pagorki.html",
      "slug": "pagorki",
      "title": "Post Title",
      "date": "2021-07-18",
      "distance": 65.5,
      "time_spent": "6h 30m",
      "card_image_url": "/path/to/card.jpg",
      "coords": [{"route": [[52.1, 16.9], [52.2, 17.0], ...]}]
    }
  ]
}
```

**Key difference from payload.json:** No tags, no area arrays, no image_url, no category. Only posts with routes. 98% smaller.

## `/jsons/photo_grid.json` — Photo Coordinates Only

**Generator:** `PhotoGridJsonGenerator` (priority 56)
**Size:** ~14 KB
**Used by:** planner.js (photo planner page)
**Filter:** Only photos with valid EXIF lat/lon

```json
{
  "coords": [
    [52.1234, 16.5678],
    [50.0635, 19.9450],
    ...
  ]
}
```

**Key difference from photos.json:** Only coordinate pairs, no metadata at all. 99.9% smaller than photos.json.
